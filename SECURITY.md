# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately. Do not publish proof,
credentials, or sensitive details in a public issue.

Open a [private security advisory](https://github.com/protickbarman/xro-yt/security/advisories/new)
on GitHub and include:

- affected component and configuration
- reproduction steps or a minimal proof of concept
- impact and likely attack scenario
- suggested remediation, when available

Maintainers will acknowledge reports where possible, investigate the issue,
and coordinate a fix and disclosure timeline. Response times are not guaranteed.

## Scope

This policy covers code and workflows in this repository, including its Docker
configuration. It does not cover third-party services, upstream providers,
external proxies, or deployments operated outside this repository.
